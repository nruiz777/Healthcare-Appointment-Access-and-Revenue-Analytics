Healthcare-Appointment-Access-and-Revenue-Analytics
Analyzing No-Shows, Payer Performance &amp; Revenue

Project Overview

This healthcare analytics project analyzes appointment scheduling,
no-show behavior, payer performance, and
revenue.

The goal was to identify operational patterns that could contribute
to missed appointments, incomplete follow-ups, and lost expected
revenue.

Business Problem

Healthcare organizations can lose revenue and reduce patient access
when appointments are missed, cancelled, rescheduled, or when
required follow-ups are not completed.

This project uses appointment-level data to identify areas of
operational and financial risk.

Tools Used

- Microsoft Azure SQL
- Power BI
- Excel
- GitHub

Dataset

The dataset contains 1,000 synthetic appointment records.

Key fields include:

- Patient ID
- Provider
- Appointment Date
- Appointment Type
- Appointment Status
- Follow-Up Required
- Follow-Up Completed
- Payer
- Expected Revenue
- Actual Revenue
- Revenue Gap

No real patient information is used.

Key Metrics

- Total Appointments: 1,000
- No-Show Rate: 14.60%
- Expected Revenue: $131,425
- Revenue Gap: $48,306

Analysis

No-Show Analysis

The dashboard analyzes no-show rates by:

- Provider
- Appointment Type

The highest provider no-show rate was 18.0%.

The highest appointment-type no-show rate was 16.9%.

### Revenue Analysis

Revenue analysis examines expected revenue, actual revenue,
and revenue gaps across appointment outcomes and payers.

Commercial had the largest dollar revenue gap at approximately
$17,000.

### Payer Analysis

Payer performance was analyzed using:

- Appointment volume
- Expected revenue
- Actual revenue
- Revenue gap
- Revenue gap percentage

## Recommendations

Potential operational improvements include:

1. Investigate providers and appointment types with elevated
   no-show rates.

2. Develop targeted appointment reminder or confirmation
   workflows.

3. Review payer groups with significant revenue gaps.

4. Monitor cancelled and no-show appointments for potential
   revenue leakage.

5. Improve follow-up tracking for appointments requiring
   additional patient contact.
